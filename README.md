## 🚀 Featured Projects

<details>
<summary><b>🔍 SAM Intelligent Data Extraction Agent</b></summary>
<br/>

Production-ready Streamlit application built for Ernst & Young's Software Asset Management practice. Automates extraction of critical licensing metadata — Vendor, Product, Version, License Metric, End of Support, and End of Life — directly from vendor URLs, using SerpAPI-grounded search combined with LLM inference via Groq and OpenAI.

| Attribute | Details |
|---|---|
| **Stack** | Python, Streamlit, SerpAPI, Groq API, OpenAI API, Pandas |
| **Scale** | Single-record and batch Excel processing modes |
| **Performance** | Structured 7-field extraction per query with LLM-based normalization |
| **Security** | API key isolation, no persistent storage of client vendor data |
| **Impact** | Reduced manual SAM data-entry effort across licensing audits |
| **Repository** | *Private — Enterprise Engagement* |

</details>
